💻 Portfólio Web - Desenvolvedor Web

##  Sobre o Projeto

Este projeto foi desenvolvido como parte de uma atividade do curso de **Desenvolvimento de Sistemas no SENAI**.

O objetivo foi criar uma página de **Portfólio/Currículo Web**, utilizando HTML semântico para organizar informações pessoais, habilidades, projetos e um formulário de contato.

---

## Objetivo

Desenvolver uma página web simples, organizada e funcional, aplicando conceitos de **HTML5 semântico**, estruturação de conteúdo, tabelas, links internos e formulários.

---

##  Tecnologias Utilizadas

- HTML5
- HTML Semântico
- Formulários HTML
- Tabelas HTML
- Links internos
- GitHub
